# gilliandelvigne.be

**Français** · [English](#en)

Mon portfolio. Reprise d'un portfolio personnel existant, reconstruit sur Next 16 : App
Router, Server Components, contenu compilé hors du bundler.

## Ce que le site fait

Chaque projet porte un profil de difficulté sur six axes (étendue, couplage, enjeu,
conformité, densité de règles, pluridisciplinarité) et chaque valeur est affichée à côté du
fait qui la justifie. Un écosystème qui tient cinq services externes et un shell qui réplique
`bash` jusqu'à ses codes de sortie ne sont pas difficiles de la même façon. La forme le dit
avant le texte.

## Stack

| | |
|---|---|
| Framework | Next 16, App Router, Server Components |
| Contenu | MDX compilé par Velite hors du bundler |
| Langues | français et anglais, avec une bascule qui conserve la position exacte par une clé de traduction |
| Styles | Tailwind v4, tokens CSS à rôles assignés |
| Tests | Vitest et Testing Library |

My portfolio. A rebuild of an existing personal portfolio on Next 16: App Router, Server
Components, content compiled outside the bundler.

### What the site does

Every project carries a difficulty profile across six axes (scope, coupling, stakes,
conformance, rule density, cross-disciplinarity) and each value sits next to the fact that
justifies it. An ecosystem holding five external services and a shell that replicates `bash`
